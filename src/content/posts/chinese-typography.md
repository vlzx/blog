清晨，阳光落在书桌的一角。打开电脑，写下今天的第一行文字：保持好奇，慢慢积累。博客不必总有宏大的主题，一次尝试、一点发现、一段值得记住的经历，都可以成为记录的起点。

这是一篇中文排版示例。你可以在电脑和手机上阅读，也可以切换明暗主题，观察汉字的笔画、标点的位置，以及长段落是否舒适易读。

## 字体与阅读

本站正文与界面的中文、英文和数字统一使用 LXGW WenKai（霞鹜文楷）。字体文件随站点一起提供，无需在设备上预先安装。字体尚未加载或缺少相应字形时，浏览器会依次尝试设备上的苹方、思源黑体和微软雅黑，最后使用系统的后备字体。当前使用常规字重，加粗与斜体效果由浏览器合成。

**这是一段加粗文字，用来观察标题与重点内容的字重。** 普通正文则更适合平稳的阅读节奏，让每一句话自然衔接，不必急着跳到结论。

## 中英文混排

这个博客使用 AstroPaper 构建，部署在 Cloudflare Pages。写作时，我们经常把中文、English、数字 0123456789 和技术术语放在同一个段落里，例如：使用 Markdown 记录笔记，在 GitHub 管理代码。

常见中文标点也值得看一看：逗号，句号。问号？感叹号！分号；冒号：以及“引号”、（括号）、《书名号》和省略号……

## 一份小小的阅读清单

- 看看「春夏秋冬、山川湖海」的笔画是否清晰。
- 比较普通正文和 **加粗文字** 的视觉差异。
- 缩小窗口，观察长句换行和段落间距。
- 切换明暗主题，感受文字与背景的对比。

> 写下来，不是为了立刻得到答案，而是给思考留下可以继续生长的地方。

## 代码与正文

行内代码与代码块使用同样由本站提供的 Google Sans Code 等宽字体，其中的中文使用霞鹜文楷。可以用行内代码 `npm run dev` 观察它与正文的区别，也可以看看代码块中的缩进和符号是否清晰：

```js
const message = "你好，世界！";
console.log(message);
```
